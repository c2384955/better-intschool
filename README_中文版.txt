Better Intschool
==============================================================

适用网站：https://shc.intschool.cn
当前版本：1.00

功能
----------
  · 成绩查看与模拟：看到每门课的真实总评与任务明细，改分数试算"如果考这个分，总评会变多少"
  · 目标 GPA 规划：输入目标 GPA，反推每门课期末考需要考多少分，用于规划期末考试
  · 截止日期提醒：筛选栏常驻 ⚠ 按钮，列出所有未完成的在线任务与截止时间
  · 任务提醒与标记：自动检测需要线上提交的任务，浮出提醒。也可手动标记任务，常驻提醒
  · 往年成绩与多年 GPA 走势：查看G9-12 GPA总览，拉取报告自动计算

所有数据都只在你自己浏览器里计算和保存，脚本不会做任何上传和越权操作。

       https://chromewebstore.google.com/detail/dhdgffkkebhmkfjojejmpbldmpobfkfo
   · Edge 也可以走它自己的官方加载项商店（两者都是官方）：
       https://microsoftedge.microsoft.com/addons/detail/iikmkjmpaadaobahmlepeloendndfphd
   · Firefox：
       https://addons.mozilla.org/firefox/addon/tampermonkey/

2. 安装脚本（二选一）：
   · 方式一：打开下面的链接，Tampermonkey 会弹出安装页，
     点「安装」即可。

怎么用
------

【成绩册页面】/points
 按照学校的公式，经过验证，年度GPA计算为S1F和S2F按照科目学分的加权平均。其中S1F和S2F，期末考试S1E和S2E各占20%，剩余为S1P和S2P，由各个科目的syllabus决定不同类型的任务的占比。本插件提供经过验证的模拟计算和精确显示，可以”编辑“任务成绩来模拟给定情况下的成绩变化。

【筛选栏上的控件】
  从左到右：学年 | 学期 | ⚠ 未完成任务 | 计算 ▾ | 显示 ▾

  · 学年：切到往年学年，看历史成绩与多年 GPA 走势
  · 学期：只影响「详情」补出来的那几列（学校自己发布的列是学年口径，切不了）
  · 计算 ▾：
      - 目标GPA计算：输入目标 GPA，算出各科期末考需要达到的分数。
        支持"只调期末考"和"按比例分摊到各科"两种模式；各科明细收在可展开的条带里，
      - 清空模拟：把本地的模拟全部还原成学校原本显示的样子。
      - 添加虚拟任务：自己加一条任务参与平时成绩试算（只存在你本地，不影响学校数据）
  · 显示 ▾：
      - 详情：把学校还没发布的成绩列也列出来（这几列是本插件的估算值，
        外观与学校发布的列一致），同时把小数位切到 2 位
      - G9-G12 总览：多年 GPA 趋势图 + 各学年成绩一览

【截止日期提醒】
  筛选栏右侧常驻 ⚠ 按钮：
    · 没有未完成任务时显示灰色"⚠ 无未完成任务"，此时悬停不会弹窗
    · 有任务时悬停弹出卡片，按科目分组显示任务名与截止时间
    · 每行右侧的开关可以单独关闭该任务的提醒（会记住）
    · 点任务名直接跳到该任务详情页

【任务标记】（用来记住"我还没交/我要复查"的任务）
  标记过的任务会被【无条件当成未完成】，不管系统里是否已提交、是否过了截止时间，
  都会出现在 ⚠ 列表里并带红色"标记"徽标。
  标记只存在你自己的浏览器里，不会同步给老师或同学。

  三个入口：
    · 任务详情页（/teaching/assignmentDetail/...）：任务标题右边的小图标，左键或右键切换
    · 任务列表（/teaching）：把任务名【往上拖】到筛选栏的黄色虚线框里，松手 = 标记/取消
    · 提醒卡片里：把任务名【往下拖】到表格的红色实线框里，松手 = 取消标记

  取消标记还有更快的办法：列表行里的黄色小旗，左键或右键点一下即可；
  或者在已标记的那一行上点右键。

【关于红色的 * 星号】
  如果某门课的平时成绩，学校给的分和按任务明细算出来的分对不上（差超过 0.1），
  这门课会标上红色 *，表示"这学期的模拟仅供参考"。
  插件会在你打开成绩册时自动尝试校准；校准后如果对上了，* 会自动消失。
  带 * 的科目会自动再试一次（每科最多 2 次）；仍未消掉就说明学校给的分与任务明细
  确实对不上，这门课的模拟仅供参考。没有手动校准的按钮 —— 校准是自动的。

【往年成绩】
  在筛选栏的「学年」下拉里切到往年学年即可查看历史成绩与多年 GPA 走势图。


遇到问题怎么办
--------------
1. 先刷新页面。注入的控件活在当前页面里，刷新会重建。
2. 或者清空缓存：F12>应用>存储>依次选择本地存储和会话存储，删除其中内容。
   这个步骤会清空网页引导完成情况、所有模拟数据，可能丢失未提交的作业。
3. 生成报告：打开浏览器控制台（F12 → Console），执行：
     __INTS_DIAG()
   会生成一份自检报告，点「复制报告」把内容发到群里给我。报告里包含版本号、浏览器、
   各接口是否正常、异常记录等，不含你的账号、密码或 token 明文。
   然后把报告发给 chace.chen.stu@dipont-hc.com，可以直接发我，也可以简要描述情况，感谢。


可选设置（高级）
----------------
在浏览器控制台执行（改完刷新页面生效）：

  换标记图标：      localStorage.setItem('ints_mark_icon','flag')
                    可选 tag（默认）/ pushpin / flag / highlight
  关闭自动校准：    localStorage.setItem('ints_auto_calibrate','0')
                    打开成绩册时不再自动校准星标科目（减少请求量）
                    改回 '1' 或用 localStorage.removeItem('ints_auto_calibrate') 恢复
  关闭诊断日志：    localStorage.removeItem('ints_diag')
                    默认就是关闭的，只有排查问题时才需要开
  关闭页面内联：    localStorage.setItem('ints_inline','0')
                    成绩册页面上不再注入 GPA / 模拟值 / 「详情」与工具栏，
                    只剩截止日期提醒（⚠）与任务标记
                    改回 '1' 或用 localStorage.removeItem('ints_inline') 恢复


卸载
----
1. 打开 Tampermonkey 面板 → 找到 "Better Intschool" → 删除（或把开关关掉）。
2. 想顺便清掉本地数据，在控制台执行：
     Object.keys(localStorage).filter(k=>k.indexOf('ints')===0).forEach(k=>localStorage.removeItem(k));
   这会清掉你的模拟数据、任务标记、目标 GPA 等。不清也不影响什么，
   它只存在你自己的浏览器里。


常见问题
--------
Q：成绩不准 / 和我自己算的不一样？
A：插件会自动校准；若平时成绩和明细仍然对不上，这门课会带
   红色 *，表示学校给的分与任务明细不一致，此时以学校系统的分数为准。

Q：为什么成绩册上有些科目没有我改的分？
A：只有能对上「科目 + 课程名」的行才会被注入；像"自修 / 会议 / 学生生活"这类
   不算成绩（算了也不进成绩册）的行本插件完全不碰，保持学校原样。

Q：刷新后页面上没出现功能？
A：先刷新页面。若页面结构被学校更新过，可能暂时失效，把自检报告（控制台执行
   __INTS_DIAG()）发我。

Q：我改的分、加的虚拟任务、标记存在哪？
A：全在你自己的浏览器里（localStorage）。换电脑、换浏览器、清站点数据就没了

Q：模拟会不会影响我的真实成绩？
A：不会。模拟只改本地内存和 localStorage，从不上传，也不调用任何写接口。

Q：会一直请求学校接口吗？
A：不会。未完成任务的检查每 15 分钟才跑一次；切回标签页也不会疯狂补查（最少间隔 2 分钟）；
   自动校准每科最多 2 次、每个会话最多 20 门课。所有请求都是同源的只读 GET。

Q：会不会消耗很多流量 / 被老师发现？
A：插件不发送任何数据给第三方，也不修改服务器数据；请求特征与正常浏览页面一致。已获IT老师授权，放心用。

Q：手机上能用吗？
A：没有适配。仅支持桌面版 Chrome / Edge / Firefox。

Q：新版本怎么更新？
A：用上面链接安装的版本，篡改猴会定期检查更新并提示；也可以在篡改猴面板里手动点
   「检查用户脚本更新」。


声明
--------
  · 本脚本是非官方辅助工具，与学校、Intschool 官方无关。
  · 所有分数均为本地估算，可能存在误差，【最终成绩一律以学校系统显示的为准】。
  · 任务标记、模拟数据、目标 GPA 全部只保存在你自己的浏览器 localStorage 中，
    仅本机可见，不参与任何评定，也不会上传。
  · 脚本只读取学校接口数据，不修改服务器上的任何内容。
